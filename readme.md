
# Calculadora em Python

## Sobre o projeto

Este projeto consiste em uma calculadora simples desenvolvida
em Python, com operações matemáticas básicas.

## Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão
- Verificação de divisão por zero

## Tecnologias utilizadas

- Python 3.12
- Git e GitHub
- GitHub Actions para automação da pipeline

## Como executar

1. Instale o Python 3.12 ou superior.
2. Clone este repositório.
3. Abra o terminal na pasta do projeto.
4. Execute:

```bash
python main.py
```

## Pipeline CI

O projeto utiliza GitHub Actions para automatizar
a verificação da sintaxe do código a cada push
ou pull request.
